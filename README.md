## 📄 Overview

This project focuses on replicating a multi-column form layout based on a provided design mockup. Key highlights include a full-height sidebar background, a responsive form container, custom typography using Google Fonts, and a structured CSS Grid layout for input fields.

## 🛠️ Built With

* **HTML5** – Semantic markup and form validation attributes
* **CSS3** – Flexbox, CSS Grid layout, and custom typography styling
* **Google Fonts** – *Roboto* and *Caveat* for custom cursive accents
* **Git & GitHub Pages** – Version control and live deployment

## ✨ Key Features

* **Split-Screen Layout:** Built with Flexbox, utilizing full viewport height (`100vh`) with an auto-scaling sidebar background (`background-size: cover`).
* **Two-Column Form Grid:** Leverages CSS Grid (`repeat(2, 1fr)`) to cleanly arrange input controls into structured pairs.
* **Form Inputs & Validation:** Native HTML5 form field requirements and password confirmation pairing.
* **Custom Styling:** High-contrast submit button with hover transitions and subtle card elevation styling.
